# NYC Protected Streets

GitHub Pages-ready version of the interactive NYC Protected Streets visualization.

## Files to upload
- `index.html` — complete website, including styles, JavaScript, and map data.
- `.nojekyll` — tells GitHub Pages to serve the site as static files without Jekyll processing.
- `README.md` — project notes only; it is not required for the website to run.

## GitHub Pages
1. Upload these files to the root of the repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose `main` and `/ (root)`.
5. Save and wait for the deployment to finish.

The map is self-contained in `index.html`, so there are no external local data files or JavaScript files that can break because of GitHub Pages paths.
